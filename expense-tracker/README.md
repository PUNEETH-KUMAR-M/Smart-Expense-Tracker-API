# Smart Expense Tracker

This repository contains the Maven and Spring Boot project skeleton for the Smart Expense Tracker. Features will be implemented incrementally in separate milestones.

## Structure

The `com.expensetracker` package is organized into `config`, `controller`, `dto`, `exception`, `model`, `repository`, and `service` layers. The top-level `tests` directory is retained for future JUnit tests.

## Requirements

- Java 21
- Maven 3.9+

## Commands

```bash
mvn clean install
mvn spring-boot:run
mvn test
```
